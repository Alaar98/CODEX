# TRACE project guidance

- The mission is TRACE: Tracking and Reacquisition Architecture for Cooperative
  Estimation of Uncorrelated Space Objects. Python, without AI.
- Record modelling assumptions, changes, data provenance and limitations in
  `Notas del Proyecto.md`. Distinguish measured data from synthetic hypotheses.
- All new plots must use the shared scientific publication style in
  `src/space_debris_detection/plotting.py`: serif text, Computer Modern math,
  clean axes, explicit units/bins and 300 dpi PNG only. For population
  maps use 2D counts, white empty cells, inferno_r and a logarithmic colourbar.
  Histograms show counts, not density, unless explicitly requested otherwise.
- Never label uniform or assumed orbital distributions as empirical. Preserve
  catalogue origin, selection, dates, frames and limitations. Do not silently
  propagate or relabel GP/TLE mean elements as common-epoch osculating states.
- Use the existing checkout. Do not create a worktree unless explicitly asked.
- Reproduce the full delivered population with `bash scripts/reproduce_population.sh`
  after installing requirements. Its fixed orbital epoch is 2026-11-05T00:00:00Z,
  frame TEME. Do not silently reset it to the earlier inclination-only mode.
- All five original CelesTrak CSV files are archived under data/raw/celestrak.
  Keep their bytes unchanged; provenance.json contains the source hashes.
  The active GP file is not a debris donor. Three-family extrapolation is
  flagged per object and must not be described as globally representative.
- The existing trace_population_50000.csv is the nominal baseline. Sensitivity
  alternatives live under data/generated/sensitivity and are generated by
  scripts/generate_sensitivity_populations.py. Preserve nominal CSV, metadata
  and validation bytes when producing alternatives. There are nine alternatives
  (three per parameter), not a Cartesian combination. Keep a, i and M fixed.
  Circular omega is a numerical gauge, flagged undefined; physical u is uniform.
- Angular sensitivity scenarios must use exactly 12, 8 and 4 equally spaced
  RAAN planes or perigee-argument positions, starting at 0 degrees. No jitter,
  continuous uniform law or wrapped Gaussian. Balance group counts to within
  one object and randomize membership reproducibly. Superseded angular files
  are retired after verifying they are the generator's unmodified outputs.
- outputs/ must contain only PNG images, recursively. Use trace_nominal_ for
  nominal images, trace_<scenario_id>_ for alternatives, and trace_comparison_
  with the compared populations in the filename for comparisons. Store figure
  manifests under data/generated/, never inside outputs/.
- Optical studies run with scripts/generate_optical_validation.py and read the
  Excel directly. High Gain uses 15000 electrons/pixel full well. The >140000
  low-gain bound is not an exact capacity and must not be combined with High
  Gain read noise to claim Low Gain performance. Use peak pixel charge, not
  integrated streak signal, to test saturation. Optical curves are conditional
  instrument results, not population detection counts; keep the populations intact.


## Local document skills

- For technical documents requested in LaTeX, TeX or Overleaf, or explicitly
  invoking `$documentos-tecnicos-latex`, read and apply
  [.agents/skills/documentos-tecnicos-latex/SKILL.md](.agents/skills/documentos-tecnicos-latex/SKILL.md).
- For technical documents requested in Word or DOCX, or explicitly invoking
  `$documentos-tecnicos-word`, read and apply
  [.agents/skills/documentos-tecnicos-word/SKILL.md](.agents/skills/documentos-tecnicos-word/SKILL.md).
- Each skill is self-contained: read its references/estilo.md and use its
  supplied template and assets when authoring the requested document.
  Scope these instructions to document tasks. Preserve TRACE model provenance,
  scientific conventions and the shared plot style.
- Put report sources and document deliverables (TEX, DOCX, PDF and supporting
  vector drawings) under docs/reports/<report-name>/, using relative paths.
  The outputs/ directory remains PNG-only.
- Uploaded skill files are preserved byte-for-byte; archive and file hashes
  are recorded in docs/skills-provenance.json.
