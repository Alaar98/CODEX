# Concepto de misión

Estado: pendiente de definir a partir de la idea de misión.

## Preguntas iniciales

1. ¿Observación desde tierra, desde una plataforma espacial o desde varias?
2. ¿Qué tamaños y regímenes orbitales de basura se pretende detectar?
3. ¿Detección pasiva de luz reflejada, emisión térmica o iluminación activa?
4. ¿Qué geometría y estrategia de observación hacen singular la propuesta?
5. ¿Qué métrica define el éxito: cobertura, tamaño mínimo, revisita, precisión
   angular o número de detecciones, y con qué restricciones de recursos?

## Trazabilidad del estudio

Para cada escenario, registrar valores, unidades, fuente y justificación de
las hipótesis; separar datos de referencia de parámetros exploratorios.
Documentar criterios de aceptación, sensibilidad e incertidumbre antes de
interpretar una solución optimizada como viable.

## Próximas etapas

- Definir criterio de detección y métricas de misión.
- Explorar el espacio de diseño y las restricciones.
- Contrastar los modelos con referencias o casos verificables.
